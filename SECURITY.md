# Security policy

Project Ink is under active development and does not yet publish supported
release versions or response-time commitments. Please keep vulnerability
reports private until maintainers have assessed and addressed them.

Use [GitHub private vulnerability reporting](https://github.com/jcd1991/project-ink/security/advisories/new)
to contact the maintainers. Private reporting is enabled for this repository.
Do not include
project files, artwork, recovery checkpoints, or diagnostic traces in a report
unless they are necessary; traces can contain local paths and artwork data.

Before the first supported release, maintainers must publish supported versions
and a response policy. The private reporting route does not establish a
response-time commitment.
