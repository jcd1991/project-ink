# Security policy

Project Ink is under active development and does not yet publish supported
release versions or response-time commitments. Please keep vulnerability
reports private until maintainers have assessed and addressed them.

For a public GitHub repository, use its private vulnerability-reporting feature
when it is enabled. If that feature is unavailable, contact the maintainers
through the private contact route listed by the repository host. Do not include
project files, artwork, recovery checkpoints, or diagnostic traces in a report
unless they are necessary; traces can contain local paths and artwork data.

Before the first public release, maintainers must enable and verify a private
reporting route and publish a response policy. This file does not claim that
such a route is currently configured.
